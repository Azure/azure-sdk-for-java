# Release History

## 1.0.0-beta.1 (2026-11-18)

- Azure Resource Manager Cost Management Price Estimation client library for Java. This package contains Microsoft Azure SDK for Cost Management Price Estimation Management SDK. Estimates prices for proposed configurations using subscription-applicable prices. Package api-version 2026-10-01-preview. For documentation on how to use this package, please see [Azure Management Libraries for Java](https://aka.ms/azsdk/java/mgmt).
